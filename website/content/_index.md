开源开发工具周报（**OSDT Weekly**）是由 [HelloGCC](https://hellogcc.github.io/) 与 HelloLLVM 社区发起和维护的摘要类周刊，内容覆盖 GCC、LLVM/Clang、GDB、Binutils、glibc、QEMU、TVM、RISC-V 等开源开发工具与社区的一周动态，每周三发布。

每期分「近期活动预告」「编译社区的八卦信息」「本周工具链岗位」等板块，GCC、LLVM、QEMU 等各自成节，通常是邮件列表、代码评审与社区讨论的要点摘录。

- 内容以 Markdown 维护在 [GitHub 仓库]({{< param "github" >}}) 的 `weekly-<年份>/` 目录下，欢迎提 Issue 与 PR 补充线索。
- 想引用或转载，请注明来源与对应期号。
