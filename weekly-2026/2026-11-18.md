### RT-Thread 社区

- BLK_PARTITION ioctl 把用户态裸指针直接当内核写地址, 非特权进程可任意改写内核内存, 修复新增 294 行：[drivers][block] prevent arbitrary kernel write via BLK_PARTITION ioctl on RT-Smart](https://github.com/RT-Thread/rt-thread/pull/11981)
- serial_v2 的 DMA ping 缓冲恒偏出 32 字节 cache 行 12 字节, STM32H7 上失效越界踩坏相邻堆块：[Bug] serial_v2: DMA rx ping buffer is not cache-line aligned — D-cache invalidate overruns into the adjacent heap chunk (STM32H7: tx_fifo ringbuffer header reverts, next write asserts)](https://github.com/RT-Thread/rt-thread/issues/12063)
- RISC-V 切换上下文漏存 fs0 至 fs11 与 fcsr, 两个浮点线程互读对方结果, 五个文件补 117 行：[libcpu][riscv] fix: preserve FPU state across context switches](https://github.com/RT-Thread/rt-thread/pull/12006)
- 芯擎 D213 板级包三天走完评审合入, 平头哥 C906 配 128 MiB DDR3, 三十个文件新增 1783 行：[bsp][artinchip] Add initial D213ECV-DEMO-V4-0 support](https://github.com/RT-Thread/rt-thread/pull/12058)
- iso9660 目录名长度为 0 或 1 时减法下溢成无界内核写, 报告后十七分钟出修复：[dfs][iso9660] fix: validate directory record name length](https://github.com/RT-Thread/rt-thread/pull/12062)

### AI Compilers

- FlagTree 把昇腾后端整体迁到 Triton 3.6.x, 一次改 1286 个文件, 新增 30.7 万行并补 200 多个算子单测：[Ascend] Add Ascend backend support for Triton 3.6.x](https://github.com/flagos-ai/FlagTree/pull/1637)
- Torch-FL 八天八笔把 Qwen3-0.6B 热启动 CPU 提交从 211 毫秒压到 28 毫秒, 为厂商 PyTorch 的 1.17 倍：[perf: add generated native FlagGems hosts for eager inference](https://github.com/flagos-ai/Torch-FL/pull/824)
- TileOPs 把 W4A16 解码瓦片分给两个 consumer warpgroup, 七条解码行快 10 至 20%, 对 marlin 至少 1.20 倍：[Perf][foundry][GEMM] Decode deferred-scale W4A16 tiles on two consumer warpgroups](https://github.com/tile-ai/TileOPs/pull/2955)
- triton-riscv 周正式版给 riscv64 轮子加 -O3 与 +zvfbfmin, 产物 502 MiB, 版本 triton-3.9.0：[triton-riscv 2026-11-15-e99c326](https://github.com/RuyiAI-Stack/triton-riscv/releases/tag/release%2F20261115-e99c326)
- IREE 3.14.0 给 RISC-V V 补 f16 与 bf16 的 inner_tiled MMA, math.roundeven 在 riscv64 上走原生指令：[Release v3.14.0](https://github.com/iree-org/iree/releases/tag/v3.14.0)
