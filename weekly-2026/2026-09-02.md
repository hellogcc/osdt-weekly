### LLVM/Clang/LLDB/LLD

本节内容来自 [LLVM Weekly 第 661 期](http://llvmweekly.org/issue/661)，
[Alex Bradbury](https://www.linkedin.com/in/alex-bradbury/) 大哥持续稳定输出。

- LLVM 23.1.0 [已发布](https://discourse.llvm.org/t/llvm-23-1-0-released/91654)。
- 一篇关于 mold 链接器的论文现已[上线 arXiv](https://arxiv.org/pdf/2608.23228)。
- 嵌入式工具链研讨会(Embedded Toolchains Workshop)的 BoF 分会场提案[现已开放提交](https://discourse.llvm.org/t/2026-llvm-developers-meeting-embedded-toolchains-workshop/91645),该研讨会将在 LLVM 开发者大会(LLVM Developers' Meeting)主会之前举行。
- Matt Arsenault 提议[将 MachineIR 改为使用 block arguments 而非 PHI 节点](https://discourse.llvm.org/t/rfc-change-mir-to-use-block-arguments-instead-of-phis/91657),这与 MLIR 的做法类似。
- 看起来很有意思： Vincent Arcila 发布了一篇关于 [LLVM GPU 目标 InputGen 基础设施](https://discourse.llvm.org/t/rfc-inputgen-infrastructure-for-llvm-gpu-targets/91660)的 RFC 提案。"该 RFC 提议为 GPU InputGen 添加编译器和运行时基础设施。InputGen 是一种能够为给定 GPU 设备函数自动生成可运行、有状态输入的工具。该工具允许用户为任何 GPU 函数生成数千个输入,使用这些输入重新执行函数,并分析函数的运行时行为,用于性能分析、正确性验证或调试。"
- 嵌入式的伙伴可以看看：Volodymyr Turanskyy 发起了一场关于 [LLVM libc 裸机文件 IO 支持原型](https://discourse.llvm.org/t/rfc-llvm-libc-bare-metal-file-io-support-prototype/91662)的 RFC 讨论。
- 国内也有小伙伴在贡献： Bruno Cardoso Lopes 发布了 [ClangIR 2026 年 8 月进度报告](https://discourse.llvm.org/t/clangir-progress-report-august-2026/91685)。
- 日积跬步：在 LLVM libc 中实现了 float80 仿真。[dd82a72](https://github.com/llvm/llvm-project/commit/dd82a72885c8)。

### RISC-V in China

- SiFive BigSky 进入交付阶段, 服务器级 RISC-V 密集落地(8/28): BigSky(32 核服务器 CPU)正式进入交付阶段,首批系统已在领先客户运行实际负载,Futurum 分析师发文解读;同期赛昉「昉·天枢-100」宣布正式交付(8/30 补收录),成为国内率先达到可交付状态的服务器级 RISC-V CPU IP——服务器叙事从"发布"转向"交付",商业化元年信号明确。
- 国内 RISC-V 资本化里程碑: 芯来挂牌、奕斯伟 IPO(8/25-8/30)。芯来科技在新三板创新层正式挂牌(代码 875127),国内 RISC-V CPU IP 龙头登陆资本市场;奕斯伟计算 IPO 招股书披露细节,报告期累计亏损超 52 亿引发业内讨论——头部厂商密集走向资本市场,行业进入"烧钱换生态、融资续命"的加速整合期。
- 香山大规模合入:68+ 笔提交,跨月成果落地(8/28): 香山(OpenXiangShan)单日窗口合入 68+ 笔提交,覆盖 ZICBO、Zvknha/Zvbb 扩展支持、向量单元重构与 AMOCAS 等,系跨月开发成果的集中收敛;此前一周(8/27)还有 66 笔微架构性能优化与验证分析提交,持续保持国产高性能核的高强度迭代。
- MIPS 加入 RISC-V 顶级会员,领衔物理 AI 开放标准(8/27):MIPS 成为 RISC-V International 顶级会员(Premier),并领衔物理 AI 开放标准工作——昔日竞争指令集玩家的转向,佐证 RISC-V 在具身智能/物理 AI 时代的聚拢效应。
- 工具链与生态多点开花(8/26-8/30):GCC 为 RISC-V 添加  -mcpu=native/ -mtune=native 支持(首次原生 CPU 探测);乐鑫 esp-nn 1.3.1 发布(RISC-V 内核全连接层向量化);进迭时空 K3 BSP v1.0.7 与 Bianbu V4.0.6 同日发布;开放原子紫金专区 OPC 孵化行动计划启动,RISC-V 开源芯片产业创新中心落地苏州试点;具身智能侧深开鸿发布 M-Robots OS 3.0 Beta,重心转向群体智能。

### RT-Thread 社区

RT-Thread 进入 v5.3.0 新版本周期的启动阶段,内核、工具链与生态多点并行推进,重点产出如下:

- v5.3.0 版本周期正式启动(8/24)：主仓库创建 v5.3.0-beta 分支,标志新一轮大版本迭代拉开帷幕;master 分支此前刚完成 NXP i.MX RT1180 的大规模 BSP 合入(I2C DMA/CAN/SPI/EtherCAT 等),为 5.3.0 积累了丰厚底料。

- 内核安全与稳健性补强(8/26-8/27)：Cortex-M4 硬件栈保护(HW Stack Guard)支持正式合入内核,提升栈溢出防护能力;同期修复 netdev 在无网卡环境下的 ping 空指针崩溃,并清理 finsh 废弃宏(移除 FINSH_FUNCTION_EXPORT_ALIAS),工程健壮性持续改善。

- 睿擎工业平台 Workshop 上海站举行(8/27)：原定 8 月 27 日的睿擎 EtherCAT 工业实时控制 Workshop 如期在上海举办,这是睿擎平台面向工业场景的重要线下布道;同期 RT-Thread 入选 2026 RTOS 性能榜单,纳入八大 RTOS 独立评测(首个国际第三方 RTOS 基准评测背书)。

- RISC-V 版图再拓:达摩院玄铁 C908 支持 RT-Thread Smart(8/29)：达摩院玄铁 C908 BSP 合入,为 QEMU virt64 平台提供 RT-Thread Smart 支持,进一步打通国产 RISC-V 核 + RT-Thread 大型系统(rt-smart)的适配路径;同期 qemu-vexpress-a9 回溯支持函数名。

- 工具链 WebUI 化与生态活跃(8/28-8/30)：ENV 工具迎来 WebUI 化落地:新增 SDK 管理与本地工具链配置,并合入插件后端服务与包更新安全加固;生态侧 packages 新增 MRamTrace(RAM 后端函数追踪与离线可视化)、BMI270 IMU 驱动、LiteType 字体引擎、AI Agent 多模态等软件包,第三方 canopennode-rtt 一周内多连更(LSS 持久化/波特率激活/SRDO);elexcon 2026 预告"不止操作系统",将秀出 AI 硬件全家桶。
