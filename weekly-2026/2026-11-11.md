### RT-Thread 社区

- 一天十一笔边界补丁里六笔直指 2024 年 CVE, FinSH、wlan、随机数、var_export、rt-link 与 YMODEM 改成先判长度再拷贝, 不再把断言当边界：[[finsh] bound path construction in msh file helpers](https://github.com/RT-Thread/rt-thread/pull/12017)
- ptyfs 注销只摘链表不释放 struct ptyfs_file, 普通用户反复 open/close /dev/pts/* 即可耗尽内核内存, 报告十二小时后出修复：[[Bug] ptyfs: ptyfs_unregister_pts() never frees the pts file — unprivileged open/close loop exhausts kernel memory and panics the kernel](https://github.com/RT-Thread/rt-thread/issues/12023)
- dfs/nfs 把服务端返回的读长度直接当拷贝长度, 超过请求或 data_len 就越界写, 修复按两者取下界：[[dfs][nfs] bound READ copy length to request and data_len](https://github.com/RT-Thread/rt-thread/pull/12012)
- RISC-V APLIC 在电平中断撤销后仍补发 MSI, 已合入的修复改为 deassert 后不再重触发：[Fix APLIC MSI retriggering for deasserted level interrupts](https://github.com/RT-Thread/rt-thread/pull/11966)
- 瑞萨 RH850 G4KH 移植提案送审, 把 utest 与 libcpu 抽象带到 ARM 与 RISC-V 之外的第三个主力架构, 并带 qemu-rh850-u2c BSP：[[libcpu][bsp] Add Renesas RH850 G4KH port and qemu-rh850-u2c BSP](https://github.com/RT-Thread/rt-thread/pull/11998)

### AI Compilers

- TileLang 主线补上 L1 与 L2 预取内建和六档驱逐优先级, 全局加载模板改为模板化 API, 非默认优先级要求 SM80 以上：[[CUDA] Add L2 prefetching instructions with optional eviction policy](https://github.com/tile-ai/tilelang/pull/3490)
- TileLang-Weft 两仓一日 40 笔提交, 553 个平台用例数值检查全过, 但快于参考实现仅 41 例, SG2044 中位加速比 0.058 倍：[Tianchen-ai/tilelang-weft](https://github.com/Tianchen-ai/tilelang-weft)
- TileOPs 把 33 至 40 token 的 W4A8 调用改走 40 token 解码瓦片, 132 SM 的 H200 上表外网格快 4.3% 至 11.3%：[[Perf][foundry][GEMM] Take 33-40 token W4A8 calls past one wave on the 40-token tile by rule](https://github.com/tile-ai/TileOPs/pull/2888)
- FlagOS Torch-FL 让 Qwen3 训练步的 17 个算子走寒武纪 CNNL, 修掉两队列无顺序约束的乱序, 耗时仍为 torch_mlu 的 1.86 倍：[perf: serve the Cambricon operators a Qwen3 training step needs](https://github.com/flagos-ai/Torch-FL/pull/809)
- buddy-mlir 把整个 f32 YOLOv8 图经 VIR 下降, 卷积沿输出通道向量化、FHWC 过滤器先转 HWCF, 一并补 rank-0 输入与保末维 reduce：[[midend][VIR] Lower the whole f32 YOLOv8 graph through VIR](https://github.com/buddy-compiler/buddy-mlir/pull/1041)
