## 编译社区的八卦信息

- 【开源自荐】[NanoAvatar](https://github.com/wpydcr/NanoAvatar)：在 Android 手机上本地生成语音驱动的数字人视频，无需云端 GPU。支持流式生成，已发布 Android 与 Web 推理源码、模型权重和可安装 APK。
  [演示](https://github.com/wpydcr/NanoAvatar#demo) · [模型权重](https://huggingface.co/wpydcr/NanoAvatar) · [Android APK](https://github.com/wpydcr/NanoAvatar/releases/latest)
- 【开源自荐】[OrcaReplay](https://github.com/Continuum-AI-Corp/OrcaReplay)：面向命令行的 AI agent 运行录制 / 重放工具。`orca` 以 HTTP 代理的形态夹在开发者的 agent 程序与模型服务之间，把一次运行的全部流量（prompt、工具调用、响应、原始字节）原样录到本地 trace，之后可在不联系任何远端服务的前提下重放这次运行、diff 两次运行的差异，或把录像 fork 到另一个模型上重跑。独立 CLI（Node 20+，`npm i -g orcareplay`，Apache-2.0），trace 留在本地磁盘，无托管服务、无日志外发；另提供 `orca mcp` 六个工具（list/show/checkpoints/graph/replay/compare）读取本地 trace 库。
- 【开源自荐】[YYLO](https://github.com/yylo-dev/yylo)：面向命令行的 AI 编码 agent 编排 CLI（`yylo` / `yy`，Node 20.10+，`npm i -g @yylo/cli`，MIT）。它把「让 agent 改一次代码」变成有边界的流程：`task start` 为每个任务冻结目标 SHA、创建独立分支/worktree，产品改动只发生在任务 worktree；`finish` 独立校验范围、脏字节、运行时与项目检查，通过后入队但不自动合并；`merge land` 在私有 detached candidate 里合成，配 Git expected-old ref 保护——合并阶段不启动模型、不选 reviewer、不排测试，测试与评审是合并之外的显式项目检查。全程留有回执（receipts：stdout/stderr、session ID、声明的哈希），agent 跑过什么、改了什么事后可查；另有 `ypl`（`yy pi --live`）交互式终端 agent 会话。
